YOUR CUSTOMIZABLE BIRTHDAY WEBSITE

HOW TO OPEN
1. Download and extract this ZIP.
2. Open index.html in Chrome, Edge, or another modern browser.
3. On a phone, it works best in a mobile browser too.

HOW TO CUSTOMIZE YOUR MESSAGES
1. Right-click index.html and open it in Notepad, VS Code, or another text editor.
2. Search for: const SETTINGS = {
3. Edit recipientName, personalLine, endingLine, and the messages list.
4. Each message has a title and body. Copy a { title: "...", body: "..." } entry to add another message.
5. Save the file and refresh the browser.

Example:
{ title: "A new note", body: "Write your message here. ♡" }

Use \n\n inside a body string to create a blank line between paragraphs.
The website is self-contained; it doesn't need an internet connection or external images.
The opening sequence has a draggable arrow and a tap-to-shoot fallback.
